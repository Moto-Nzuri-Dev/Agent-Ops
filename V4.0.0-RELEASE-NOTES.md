# Moto Nzuri Field Ops v4.0.0 — Shared Agent Onboarding Tracker

## Included
- Shared Agent Onboarding page at `/onboarding`.
- Entry fields: Date Onboarded, Agent ID, Agent Name, Shop Name, Location, Agent Phone Number, Latitude, Longitude, Projected Number of Canisters, Actual Canisters Required, Display Delivered, Onboarding Status.
- Shared read access for active administrator, Customer Care, representative, technician and driver accounts.
- Submission attribution (user email and portal role), automatic 30-second refresh, search and CSV export.
- Administrator and Customer Care status-update permission at the API layer.
- Supabase migration: `supabase/v4.0.0_agent_onboarding_tracker_migration.sql`.

## Deployment
1. Back up the current Supabase database and application.
2. Run `supabase/v4.0.0_agent_onboarding_tracker_migration.sql` in Supabase SQL Editor.
3. Deploy the full project folder using the existing environment variables.
4. Sign in to each role portal and open **Agent Onboarding**.

## Validation performed
- `node --check server.js`
- `node --check public/onboarding.js`
- `package.json` JSON parse
- ZIP archive integrity test

The application has not been connected to the live Supabase project in this environment, so live database writes and role sessions still need deployment verification.
